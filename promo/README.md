## الملفات

- `rilio-promo.html` + `promo.js`: الفيديو نفسه. افتحه في المتصفح عن طريق سيرفر محلي وهيشتغل لوحده
  (`?t=40` يبدأ من الثانية 40، و`?t=40&still` يوقف عندها).
- `music.py`: بيولّد الموسيقى والمؤثرات الصوتية (lo-fi + whoosh + كليكات)، ومفيش فيها حقوق لحد.
- `render.mjs`: بيلقط كل فريم بـ Playwright ويجمّعهم بـ ffmpeg.
- `fonts/`: خطوط Readex Pro و Baloo Bhaijaan 2 (نفس خطوط البرنامج، رخصة OFL).

## تطليع الفيديو

محتاج Node و Python 3 (مع numpy) و ffmpeg و Playwright:

```bash
python3 promo/music.py          # promo/out/music.wav
node promo/render.mjs           # promo/out/rilio-promo.mp4
node promo/render.mjs --stills 15,50,90   # صور للمراجعة بس
```

البوسترات اللي في الفيديو رسومات بألوان وأشكال توحي بكل عمل، مش البوسترات الرسمية.
